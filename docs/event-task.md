# 新新闻事件指令

收到新闻事件文件后，在当前工作区完成：

1. 读取 `docs/AGENTS.md`，再读取本次事件 JSON。
2. 读取 `docs/processing-rules.md` 和事件指定的原文；正文已下载，不运行全量采集，不补旧闻。
3. 将本篇整理稿写到事件提供的 processed 路径，保留原文文件、链接、时间及段落依据。
4. 读取 `docs/briefing-template.md` 的“新消息快讯”格式，只填本篇最相关的类别；写入事件指定的 report 路径，并在 note 路径简记执行。
5. 最终回复原样输出保存的快讯。发送由监测插件统一处理，不另发消息。

可以在一次工具请求中批量读取所需规则和原文。只使用已提供的文件读写工具，不调用子代理或其他模型。
本次没有独立行情源，影响区写新闻因素分析，未独立核验实时行情。
若阅读正文后确认与目标资产无关，最终仅输出 `SKIP: 原因`。
规则、脚本和原文为只读；仅写事件指定的三个输出文件。
