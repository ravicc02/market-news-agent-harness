# 新消息快讯模板

每个事件只输出本篇新闻和一个主要类别，类别从国际黄金、白银、原油、外汇货币对直盘、交叉盘中选择。
涉及其他品种时在分析中简述，不填五类空栏目，不合并成日报，不重复此前新闻。

## 输出格式

```text
新消息快讯｜YYYY-MM-DD HH:mm（北京时间）

类型【本篇主要类别】：

【1】title：简洁中文标题
摘要：根据本篇实际正文整理关键事实、数值和必要的来源观点，约 80～150 字。
原文链接：本篇实际文章 URL

品种走势分析：
以下为新闻因素分析，未独立核验实时行情。说明相关品种可能受到的影响、依据和不确定性，约 60～120 字。

数据说明：来源名称；新闻实际发布时间与时区；实际正文范围与必要限制。
```

## 填写规则

- 首行时间为生成时间，数据说明另写新闻实际发布时间；发现时间或生成时间不能代替原文发布时间。
- 标题、主要类别和链接均用真实内容替换占位符。链接必须来自本次事件，不能用网站首页替代。
- `full_text` 按实际正文整理；`partial_text` 在摘要开头标记 `【部分正文】`；`summary_only` 标记 `【来源摘要】`，明确仅依据来源摘要。
- 原文中的价格保留时间、单位及现货或期货口径；没有独立行情时不写成当前已核验价格。
- 作者或机构预测必须写明主体；Agent 的影响判断使用条件和不确定性。
- 总长须在 80～2,200 个字符内，尽量简短。最终正文不含内部路径、执行日志、空栏目或未替换的模板文字。
- 按事件的 `outputs.report` 保存，最终回复逐字返回该文件内容。插件负责投递，Agent 不另发消息。
- 只有明确的配置验证事件才按验证处理，仍保留原文日期；插件会添加配置验证标记，不能写成刚发布。
