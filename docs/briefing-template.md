# 简报输出模板

按以下版式输出。每类从【1】重新编号，实际条数由有效内容决定。
标题尽量用准确的中文；原文链接保留真实 URL。
占位符只能用已整理的内容填写，不能作为真实新闻输出。

```text
国际市场简报｜YYYY-MM-DD HH:mm（北京时间）

类型【国际黄金】：

【1】title：新闻标题
摘要：事实摘要；需要时注明原文观点。部分正文或来源摘要逐条标注。
原文链接：实际 URL

【2】title：新闻标题
摘要：正文摘要。
原文链接：实际 URL

类型【白银】：

【1】title：新闻标题
摘要：正文摘要。
原文链接：实际 URL

类型【原油】：

【1】title：新闻标题
摘要：正文摘要，明确 WTI、Brent 或供需事项。
原文链接：实际 URL

类型【外汇货币对直盘】：

【1】title：新闻标题
摘要：正文摘要，明确相关货币对。
原文链接：实际 URL

类型【交叉盘】：

【1】title：新闻标题
摘要：正文摘要，明确相关货币对。
原文链接：实际 URL

品种走势分析：

【国际黄金】
有依据的行情表现或新闻因素分析、判断及限制。

【白银】
有依据的行情表现或新闻因素分析、判断及限制。

【原油】
按 WTI、Brent 或实际相关范围分析。

【外汇货币对直盘】
按证据涉及的货币对分析，正确表达美元方向。

【交叉盘】
按证据涉及的交叉盘分析，关联推断明确标注。

数据说明：新闻时间窗口、实际行情日期与口径、内容缺失或采集限制。
```

栏目内没有有效条目时写出原因，不显示虚构的【1】条目。
没有独立行情时，走势分析明确写“以下为新闻因素分析，未独立核验行情”。
简报不包含内部执行日志；原文、整理稿和证据定位保存在 data 中。

## 新消息快讯

新新闻事件只输出相关类别和本篇，不填五类空栏目。建议总长在 600～1,200 个字符，最多 2,200 字符。

```text
金融快讯｜YYYY-MM-DD HH:mm（北京时间）

类型【本篇主要类别】：

【1】title：简洁中文标题
摘要：根据实际正文整理事实与来源观点，约 80～150 字。
原文链接：实际文章 URL

品种走势分析：
新闻因素分析，未独立核验实时行情。给出有依据的可能影响和不确定性，约 60～120 字。

数据说明：新闻实际发布时间；部分正文或来源摘要按实际范围标注。
```

配置验证事件仍按原文日期描述，不能写成刚发布。实际投递会由插件加“配置验证”标记。
